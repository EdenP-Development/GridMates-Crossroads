# Open decisions — don't quietly treat these as approved
| Priority | Question | Experiment |
|---|---|---|
| High | One die or two/select one? | Compare pacing, agency and turn duration |
| High | Exact finish vs pass through finish? | Check frustrating overshoots |
| High | Can a player choose a path after remaining movement? | Test natural fork flow |
| High | Which mischief effects feel fun versus punitive? | Human tests with 2–4 seats |
| High | Events chosen on landing or placed at match creation? | Compare learnability/surprises |
| Medium | Event pools' weights/cooldowns? | Monte Carlo and human balance |
| Medium | Always-visible paths and region risk? | Default yes; legibility QA |
| Medium | Can attacks target any rival or only leaders? | Compare anti-grief safeguards |
| Medium | How best to vary Quick/Classic/Long? | Handcrafted course variants before procedural |
| Medium | AI difficulty levels? | Distinguish strategic decisions, never manipulate dice |
| Medium | First theme and exact source animal tokens? | Inventory approved assets |
| Later | Alternate board shapes and chaos/cozy rulesets? | Defer until classic race feels complete |
| Later | App name availability? | Trademark and storefront clearance |
